## 📋 Descripción

**LabTrack** es una aplicación móvil desarrollada con React Native que permite a los usuarios gestionar solicitudes de prestamo y devolución de componentes informáticos de forma sencilla e intuitiva. Desde teclados y pantallas hasta ratones y microprocesadores, el proceso de devolución queda centralizado en una sola app, disponible para iOS y Android.

---

## ✨ Características principales

-  **Registro de devoluciones** — Crea y rastrea solicitudes de devolución fácilmente
-  **Catálogo de componentes** — Teclados, pantallas, ratones, microprocesadores y más
-  **Estado en tiempo real** — Seguimiento del proceso de devolución en cada etapa
-  **Historial de usuario** — Todas tus devoluciones registradas en un solo lugar

---

## 🛠️ Tecnologías utilizadas

| Tecnología | Uso |
|---|---|
| **React Native** | Framework principal para iOS y Android |

| **React Navigation** | Navegación entre pantallas |

## 🚀 Instalación

### Requisitos previos

- Node.js >= 18
- npm o yarn
- Expo CLI (`npm install -g expo-cli`)
- Emulador Android / iOS o dispositivo físico con la app Expo Go

### Pasos

```bash
# 1. Clonar el repositorio
git clone https://github.com/HugoLZ7/Proyecto_FInal_DPS441.git

# 2. Entrar al directorio
cd Proyecto_FInal_DPS441

# 3. Instalar dependencias
npm install

# 4. Iniciar la aplicación
npx expo start
```

Escanea el código QR con la app **Expo Go** en tu dispositivo para probar la aplicación.
